買い物メモ PWA v1.2

■ 主な仕様
- 上部タブ：「店で買う」「ネットで買う」「ToDo」
- 「店で買う」は日用品・食料品を1つのリストに統合
- 項目追加後、左のチェックボックスで購入済み / 完了をマーク
- チェックしただけでは項目は消えない
- 「チェック済みを削除」ボタンで、チェック済みだけをまとめて削除
- 削除直後は「元に戻す」が可能
- v1.1までの保存データをそのまま利用可能
- データはブラウザの localStorage に保存
- PWA / オフライン対応


■ v1.3変更点
- 「チェック済みを削除」→「削除」に変更
- チェックが0件のときは削除ボタンを非アクティブ表示
- 1件以上チェックすると削除ボタンがアクティブ
- 削除ボタンを「追加」ボタンと同程度のコンパクトサイズに変更
